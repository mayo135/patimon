Patimon()
===
ポケットモンスターのパロディ作品で、

パチモンの技を選んで相手を倒すターン制のゲームです。


操作方法(マニュアル)
---

* 上、下キーでわざを選び、エンターキーで決定できます。
* わざを決定した後エンターキーで行動を進めることができます。


わざ詳細
---

| 選択 | 行動 |
| -------- | :-----------------------------------------: |
| たたかう |  攻撃します |
| ためわざ | 一回ためるほどに1.2倍上昇した一撃を放てます |
| ばりあ   | 受けダメージを0にできます |


**連続選択×**
> ためわざ、ばりあは2回連続は使えません。

**ばりあ先制**

> 基本はプレイヤー先行ですが、相手がばりあを使用した場合,そのパチモンが先制攻撃になります。

工夫した点
---
パチモンを新たに追加してもclassを利用できるようなコードにしました。

参考にしたサイトのコードはif文が多く見づらかったので関数の数を増やして必要な部品を分けることでif文を減らしました。

pylint、lizardで点数が高くなるよう、コードが横に長くならないようにしたり、説明文を増やしました。


苦労した点
---
ばりあの機能を実施した際、自分のパチモンが攻撃した後に相手がばりあしてしまい、技を0ダメージにできませんでした。この問題を解決するために選択した後にプレイヤーがバリア以外を選択しているかつ、
相手がバリアを選択しているなら相手を先制攻撃するように実装しました。

HPバーの減少を体力と同期させることやアニメーションのタイミングを合わせることの実装が難しくAIやWebを参考にしながら実装した。再帰関数を使って実装したかったのですが、フレーズしまくったので、断念しました。

ゲームが面白くなるように体力及び攻撃力の調整を何度も試行しました。
例えば、たたかう連打で勝てないようにするなど。
